# Changelog

## 1.1.0-beta.1 — 2026-11-10

First semantic-versioned beta collecting the HUD development previews after 1.0.

- Add Hailstone-style minimap, external map window and player/pet heading arrows.
- Add damage/healing floats, individually styled resource bars, nameplate and camera controls.
- Add configurable death ghosts and feign-death jester effects with original editable artwork.
- Add Windows/Wine gamepad backends, two-stage keyboard/mouse mapping, held stick directions and pointer controls.
- Fix controller holds being canceled by ordinary key-down mode and normal focused UI buttons.
- Add outbound Gusto/Zeal named-pipe snapshots and an example reader.
- Include GUSTOTAG tagging and native 3D markers from the earlier tagging preview.
- Draw NPC/pet HP bars before the game's label/UI pass to retain world depth; live occlusion confirmation remains pending.
- Synchronize runtime, CMake, Windows metadata and package versions through VERSION.
- Include Windows installer, source, tests, original assets, checksums and attribution.

## 1.0

Native slow-turn and Toggle All Bags keybinds, compatibility checks and initial Windows/Wine package.
